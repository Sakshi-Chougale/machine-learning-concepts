# Single-Layer Neural Networks

An introduction to artificial neurons and single-layer neural networks, exploring how Perceptron and ADALINE learn from data using weight updates and gradient descent.

## Concepts Covered

- **Artificial Neurons:** Basic computational units inspired by biological neurons.
- **Perceptron:** A supervised learning algorithm for binary classification.
- **ADALINE:** Adaptive Linear Neuron that learns using a linear activation and error-based weight updates.
- **Gradient Descent:** An optimization technique used to update weights and reduce prediction error.
- **Feature Standardization:** Scaling features to improve the learning process.
- **Decision Boundaries:** Visualizing how a model separates different classes.

## Implementation

The notebook uses the **Iris dataset** to explore binary classification tasks.

- Implement the Perceptron learning algorithm using NumPy.
- Train the model to classify Iris flower varieties.
- Visualize decision regions and misclassification counts.
- Implement ADALINE using batch and stochastic gradient descent.
- Compare learning rates and observe changes in the cost function.
- Standardize features and visualize the resulting decision boundaries.
